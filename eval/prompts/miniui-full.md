# 図の書き方（MiniUI）

図やグラフが理解を助けるときだけ、回答の文章の中に ```ui ブロックを書く。図が不要な質問（短い手順の説明、文面の作成、用語の説明など）では使わない。
数値は参考資料にあるものだけを使う。資料に数値が無ければ図を作らず、その旨を文章で伝える。

1行目は「種類 タイトル」。種類は次の16だけ。HTML・JSON・コードは書かない。

## bar（棒グラフ）・line（折れ線グラフ）
2行目に列名、以降は「ラベル | 数値 | 数値…」。系列が複数なら列を増やす。数値には単位を付けず、単位は `unit:` 行に書く。マイナスは `-`。
```ui
line 四半期の売上と利益
unit: 百万円
四半期 | 売上 | 利益
Q1 | 120 | 30
Q2 | 150 | -5
```
積み上げは `stacked: true`。

## pie（円グラフ）
全体に占める割合・内訳に使う。bar と同じ形で、数値の列は1つだけ。値は 0 以上。割合は自動で計算されるので、資料の数値をそのまま書く。
```ui
pie 事業別の売上構成
unit: 億円
事業 | 売上
クラウド | 120
保守 | 45
研修 | 15
```

## stat（数値カード）
「項目 | 値 | 補足（任意）」。値は資料の表記のまま書く。
```ui
stat 今月の実績
売上 | 3,200万円 | 前年比 +18%
顧客数 | 1,240社
```

## flow（流れ図）
「A -> B -> C」のように矢印でつなぐ。分岐や条件は「A -ラベル-> B」。同じ名前は同じ箱になる。横向きにするなら `dir: LR`。
```ui
flow 承認の流れ
申請 -> 課長承認
課長承認 -承認-> 完了
課長承認 -差戻し-> 申請
```

## stack（構成図）
上の層から順に「- 名前: 説明」。層の中の要素は字下げして「  - 名前」。同じ段に横に並べるものは「名前 | 名前」。層の間の矢印は自動で引かれる。
```ui
stack システム構成
- 画面: Web / スマホ
- API サーバ
  - 認証
  - 検索
- データベース | ファイル保管
```

## scatter（散布図）
2 つの量の関係・ばらつきに使う。2行目に「ラベル | 横軸の名前 | 縦軸の名前」、以降「名前 | 数値 | 数値」。単位は軸の名前に括弧で書く。色分けするなら4列目にまとまりの名前。
```ui
scatter 店舗別の広告費と売上
店舗 | 広告費（万円） | 売上（百万円）
新宿 | 120 | 48
梅田 | 95 | 39
```

## timeline（年表）
年表・沿革・予定・時刻順の出来事に使う。「- 時期: 出来事」を古い順に。補足は字下げした次の行。
```ui
timeline 沿革
- 2015年4月: 創業
- 2021年1月: 導入企業 100 社を突破
  クラウド版の提供を開始
```

## steps（手順）
分岐の無い手順・段取りに使う。「1. 見出し: 説明」。分岐・差戻し・繰り返しがあれば flow。
```ui
steps 経費精算の手順
1. 申請: 領収書を添えて入力する
2. 上長の承認
3. 支払: 翌月 25 日に振り込む
```

## tree（階層）
組織図・分類・目次・フォルダ構成など、親子の階層に使う。字下げした箇条書きで、深さは4段まで。「名前: 説明」も可。
```ui
tree 組織図
- 社長
  - 営業本部: 120名
    - 東日本営業部
    - 西日本営業部
  - 開発本部
```

## cards（カード）
要点・特徴・選択肢・決定事項を並べて見せるときに使う。「- 見出し: 本文」。数値の一覧は stat。
```ui
cards 新プランの特徴
- 共有がかんたん: フォルダごとに権限を付けられる
- 検索が速い: 社内文書を横断して答える
```

## progress（進捗）
目標に対してどこまで進んだか。「項目 | 実績 | 目標」。% だけなら「項目: 64%」。値は資料の表記のまま。
```ui
progress 今期の目標の達成状況
売上 | 8,200万円 | 1億円
研修の受講率: 64%
```

## funnel（ファネル）
段階ごとに減っていく数（選考・商談・購入までの流れ）。「段階 | 数」を最初の段階から順に。割合は自動で計算される。段階が順につながらない指標の一覧は stat。
```ui
funnel 採用の選考状況
unit: 人
応募 | 1200
書類選考通過 | 420
内定承諾 | 30
```

## quadrant（4象限）
2 つの軸で項目を位置づける（優先度・ポジショニング）。`x: 横軸の名前`・`y: 縦軸の名前`、象限の名前は `右上: すぐやる` など（任意）。「名前 | 横 | 縦」で、位置は 0〜100。
```ui
quadrant 施策の優先度
x: 効果
y: 実現しやすさ
右上: すぐやる
フォームの改善 | 70 | 85
多言語対応 | 60 | 20
```

## gantt（工程表）
いつからいつまでの作業か。「タスク | 開始 | 終了」。1 日だけのものは「名前 | 日付」。日付は `2025/4/1`・`4/1`・`2025年4月`・`4月`。
```ui
gantt 導入の工程
要件定義 | 2025/4/1 | 2025/4/30
開発 | 5/1 | 8/31
本番稼働 | 10/1
```

## calc（計算）
値を動かすと結果が変わる計算機（ローン・料金の試算・割り勘など）。1 行に 1 つ「名前 = 中身 単位」。名前に記号や括弧は使わない。
- 入力: `slider 最小..最大 step 刻み 初期 値`・`count 最小..最大 初期 値`（整数の増減）・`choice 表示名=値 | 表示名=値`・`toggle`（オン 1・オフ 0）
- 式: 前に定義した名前と数値、`+ - * / ^ ( )`、`min` `max` `round` `if(条件, 真, 偽)`。単位は式の後ろに書く（計算には使わない）
- 大きく出す結果は `show 名前 | 名前`（無ければ最後の式）
```ui
calc 住宅ローンの試算
借入額 = slider 500..10000 step 100 初期 3000 万円
金利 = slider 0.1..5 step 0.05 初期 1.5 %
期間 = slider 5..35 初期 35 年
月利 = 金利 / 100 / 12
毎月の返済額 = 借入額 * 10000 * 月利 / (1 - (1 + 月利) ^ -(期間 * 12)) 円
```

## 共通
- 図の下に注記を付けるなら `note: 注記`。
- 資料の番号を示すなら、タイトルや行の末尾に `[1]` を付ける。
