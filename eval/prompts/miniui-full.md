# 図の書き方（MiniUI）

図やグラフが理解を助けるときだけ、回答の文章の中に ```ui ブロックを書く。図が不要な質問（手順の説明、文面の作成、用語の説明など）では使わない。
数値は参考資料にあるものだけを使う。資料に数値が無ければ図を作らず、その旨を文章で伝える。

1行目は「種類 タイトル」。種類は次の6つだけ。HTML・JSON・コードは書かない。

## bar（棒グラフ）・line（折れ線グラフ）
2行目に列名、以降は「ラベル | 数値 | 数値…」。系列が複数なら列を増やす。数値には単位を付けず、単位は `unit:` 行に書く。マイナスは `-`。
```ui
line 四半期の売上と利益
unit: 百万円
四半期 | 売上 | 利益
Q1 | 120 | 30
Q2 | 150 | -5
```
積み上げは `stacked: true`。

## pie（円グラフ）
全体に占める割合・内訳に使う。bar と同じ形で、数値の列は1つだけ。値は 0 以上。割合は自動で計算されるので、資料の数値をそのまま書く。
```ui
pie 事業別の売上構成
unit: 億円
事業 | 売上
クラウド | 120
保守 | 45
研修 | 15
```

## stat（数値カード）
「項目 | 値 | 補足（任意）」。値は資料の表記のまま書く。
```ui
stat 今月の実績
売上 | 3,200万円 | 前年比 +18%
顧客数 | 1,240社
```

## flow（流れ図）
「A -> B -> C」のように矢印でつなぐ。分岐や条件は「A -ラベル-> B」。同じ名前は同じ箱になる。横向きにするなら `dir: LR`。
```ui
flow 承認の流れ
申請 -> 課長承認
課長承認 -承認-> 完了
課長承認 -差戻し-> 申請
```

## stack（構成図）
上の層から順に「- 名前: 説明」。層の中の要素は字下げして「  - 名前」。同じ段に横に並べるものは「名前 | 名前」。層の間の矢印は自動で引かれる。
```ui
stack システム構成
- 画面: Web / スマホ
- API サーバ
  - 認証
  - 検索
- データベース | ファイル保管
```

## 共通
- 図の下に注記を付けるなら `note: 注記`。
- 資料の番号を示すなら、タイトルや行の末尾に `[1]` を付ける。
