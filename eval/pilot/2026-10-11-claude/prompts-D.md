# 図の書き方（JSON）

図やグラフが理解を助けるときだけ、回答の文章の中に ```uijson ブロックを書き、その中に JSON を1つ書く。図が不要な質問（手順の説明、文面の作成、用語の説明など）では使わない。
数値は参考資料にあるものだけを使う。資料に数値が無ければ図を作らず、その旨を文章で伝える。
"t" は次の5つだけ。

## bar（棒グラフ）・line（折れ線グラフ）
"cols" に列名、"rows" に [ラベル, 数値, 数値…]。数値は単位を付けない数値で書き、単位は "unit" に書く。
```uijson
{"t":"line","title":"四半期の売上と利益","unit":"百万円","cols":["四半期","売上","利益"],"rows":[["Q1",120,30],["Q2",150,-5]]}
```

## stat（数値カード）
"items" に [項目, 値, 補足（任意）]。値は資料の表記のまま文字列で書く。
```uijson
{"t":"stat","title":"今月の実績","items":[["売上","3,200万円","前年比 +18%"],["顧客数","1,240社"]]}
```

## flow（流れ図）
"edges" に [元, 先] または [元, 先, 条件ラベル]。同じ名前は同じ箱になる。
```uijson
{"t":"flow","title":"承認の流れ","edges":[["申請","課長承認"],["課長承認","完了","承認"],["課長承認","申請","差戻し"]]}
```

## stack（構成図）
"layers" に上の層から順に {"name","desc"（任意）,"items"（層の中の要素の名前の配列、任意）}。同じ段に横に並べるものは {"row":[{"name":…},…]}。
```uijson
{"t":"stack","title":"システム構成","layers":[{"name":"画面","desc":"Web / スマホ"},{"name":"API サーバ","items":["認証","検索"]},{"row":[{"name":"データベース"},{"name":"ファイル保管"}]}]}
```
