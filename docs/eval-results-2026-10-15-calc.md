# 評価結果: calc（画面内で完結する計算）2026-10-15

生データ: [eval/runs/2026-10-15-luna-calc/](../eval/runs/2026-10-15-luna-calc/)（説明の初版、calc・stat・図が要らない課題）、[eval/runs/2026-10-15-luna-calc2/](../eval/runs/2026-10-15-luna-calc2/)（説明の改訂版、calc だけ）。モデルは Luna（effort low）、各 3 回。課題は 8 件（ローン・割り勘・税込み・SaaS 料金・損益分岐点・残業代・積立・BMI）。

## 採点

課題ごとに、初期値と別の入力値（2〜3 通り）での期待値を持つ。モデルの calc の入力に同じ値を入れて計算し、結果が期待値と相対誤差 0.5% 以内なら正解。
- 入力は名前で対応付け、名前が違えば初期値の一致（単位の倍率込み）で対応付ける。範囲から外れる値は、単位の倍率（万円と円）で直す。
- 選択・オンオフの入力は、値の意味（1 が月払いか年払いか）がモデルごとに違うので、モデルの設定を総当たりして期待値が出せるかで見る。
- 結果は、名前の近い式から順に、どれかが期待値に合えばよい（単位の倍率は許す）。

- 残る失敗は、「残業代がいくらになるか計算できるようにして」のように UI を明示しない質問で、文章で計算して答えたもの。
